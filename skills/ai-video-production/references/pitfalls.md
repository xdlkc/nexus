# 模型踩坑对照表

写视频提示词时逐条对照。左边是模型最常犯的错，右边是实测有效的写法。

## 动作与人物

| 模型容易犯的错 | 应该怎么写 |
| --- | --- |
| 一群人同时做同一个动作 | 写清楚谁先谁后：「老爸第一个……过一两秒老奶奶才……小女孩最后……」；首帧也不要摆同一个姿势 |
| 本来该风做的事，人自己动手做了（比如邮差用手掀开邮包） | 写清楚原因，再写「两只手从头到尾都没有碰邮包」 |
| 人往反方向走 | 方向按画面写：「朝画面左边走，跨过左边的店门」 |
| 一个镜头动作太多就乱 | 每个镜头只写一两个主要动作 |
| 人的嘴自己在动 | 写明「人物不说话」；还动就用代码修 |
| 动作的时间和写的不一样 | 提示词里的时间只算大概，多留时间，后期用剪辑和变速对节拍 |

## 道具与物体

| 模型容易犯的错 | 应该怎么写 |
| --- | --- |
| 东西凭空出现 | 只用首帧里已经有的东西；动作要用的道具必须在首帧可见 |
| 东西的数量变了 | 数量直接写出来：「只有一封黄信封，之后他怀里全是白信封」 |
| 东西突然飞走或瞬间移动 | 写清它是怎么动的：「顺着后脑勺往后一滑，接住，扣回头上」 |
| 模型自己联想道具用法（壶总是出水） | 干脆不让这个道具出现在有动作的镜头里 |
| 雨、帽子、纹身拍着拍着就没了 | 首帧和尾帧都画上 |
| 云、月亮、植物长出眼睛和嘴巴 | 不写「卡通云」，写「蓬松的灰白色积云，只有棉絮一样的纹理和阴影」，动作只写它怎么移动 |

## 表述与歧义

| 模型容易犯的错 | 应该怎么写 |
| --- | --- |
| 一句话有两种意思（写「窗户后面的老人」，结果车里冒出了人） | 写具体：「左上角石头房子的窗口里」，再加「驾驶座一直空着」 |
| 写「不要怎么样」经常无效（写了「壶嘴不出水」还是出水） | 尽量改正面表述：「画面里一直只有首帧这几个人」 |
| 闪电画得太写实 | 写「云里闪一下白光」，再把开头剪掉 |

## Seedance 版本相关的已知问题

| 现象 | 处理方式 |
| --- | --- |
| 写了「没有音乐」还是混进了音乐（2.5） | 片段自带的声音不用，后期另外加音效 |
| 结尾几帧突然跳到尾帧的样子（2.5） | 后期选一张没问题的画面，后面都停在这一张 |
| 第一帧画面特别锐（2.5） | 直接把这一帧去掉 |
| 视频越到后面越暗越冷（2.0 mini） | 每条视频按它自己的首帧把颜色调回来 |

## 其他常见后期补救

| 问题 | 优先处理顺序 |
| --- | --- |
| 问题只在开头或结尾几帧 | 直接剪掉 |
| 颜色/亮度漂移 | 用代码按首帧对齐 |
| 推镜不够明显 | 让导演用代码再推一点 |
| 人脸轻微变形 | 先试代码修，修不好再重拍 |
| 重拍 | 必须先改提示词或首尾帧，只拍这一镜；旧片段保留，新片段不一定比旧的好 |
